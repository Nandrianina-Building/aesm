# Guide du membre
1. **Créer un compte** : « Adhérer » → matricule, identité, téléphone, mot de passe (12 caractères min.).
2. **Demander l'adhésion** : page « Mon adhésion » → soumettre. Vous êtes notifié de la décision.
3. **Payer une cotisation** : « Mes cotisations » → Payer → vous êtes redirigé vers la page de paiement. *Pour le moment, les paiements sont simulés* : choisissez « Simuler un paiement réussi » (aucun argent réel). Vous recevez un reçu et, selon la cotisation, un quitus. Plus tard, le paiement se fera par MVola / Orange Money via Tokipay.
4. **Documents officiels** : reçus, quitus, carte de membre en PDF avec QR code. Toute personne peut vérifier un QR sur `/verification/…`.
5. **Réserver un événement** : page de l'événement → Réserver ; si payant, régler dans le délai ; le billet PDF (QR) apparaît dans « Mes réservations ». Annulation possible jusqu'à 24 h avant.
6. **Documents pédagogiques** : bibliothèque filtrable par niveau, type, catégorie.
7. **Problème ?** « Mes réclamations » → nouvelle réclamation (paiement non confirmé, erreur d'information, etc.).
8. Pensez à garder votre mot de passe secret et à vous déconnecter sur un appareil partagé.
